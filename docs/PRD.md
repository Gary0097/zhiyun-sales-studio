# 智能销售中心 PRD

## 目标

为销售团队提供基于真实订单、客户与业绩数据的BI汇总、客户价值分层和业绩达成统计，全部保留来源证据并等待人工确认。

## 功能

1. 销售BI：按订单汇总营收、销量、客单价与月度趋势，输出品类/区域结构、Top产品与异常预警。
2. 客户关系管理：按近度、频次、金额(RFM)为客户分层为VIP/高价值/普通/待唤醒，输出流失风险与建议。
3. 销售业绩统计：按人员归属统计营收、单量、目标达成率与排名，判断达标状态。

## 边界

- 不自动改价、不自动派单、不修改CRM或ERP数据。
- 所有BI/客户/业绩结果进入可审阅的销售工件，等待具名人员接受后导出。

---

## 需求变更（2026-08-24）

- UI 深度重构：每个功能独立 GUI，输入为可编辑文本/表格/表单，支持「载入/导入示例数据」，结果以 KPI 卡片 + 明细呈现，不再返回裸 JSON。
- 内嵌 Agent 对话框：每个 Studio 右上角「问 Agent」，抽屉内可自动载入示例并运行功能，输出可审阅工件卡片。
- 登录与权限：企业实例内 RBAC（管理员/部门经理/财务/销售/采购/员工），决定可见 Agent、数据与知识库范围。
- 企业隔离：一套实例对应一个企业，同企业共享 Agent/数据/知识库；不同企业独立实例、独立数据目录与模型配置。
- 数据可写：各 Studio 使用 `*_STUDIO_DB` 环境变量指向可写运行时数据目录，避免只读路径导致运行失败。

详见 `docs/product/REQUIREMENT-CHANGES-2026-08-24.md`。
